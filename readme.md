# Coded TCP (CTCP): an implementation in ns3
This is an implementation of the CTCP transport layer protocol in a private fork of the ns-3 simulator. It was written as a final project for the CS856: Transport Layer Protocols course in 
the University of Waterloo. The code as-is will not compile nor run, as it depends on a private fork of the ns-3 simulator, however the main congestion control and coding/decoding logic
is cleanly separated from the rest of the simulator.
